# MVP Specifications

The MVP contains **45 user stories** across 12 epics.

This list is the scope claimed for the iteration. The full product backlog, including Post-MVP stories, is in [vision.md](./vision.md#6-user-stories).

Source: [MVP milestone](https://github.com/MESW-LES-2627/les-project-group-9/issues?q=is%3Aissue+milestone%3A%22MVP%22+label%3Atype%3Auser-story).

## E01: Catalog and navigation (#5)

- [US-001: As a shopper, I want to browse Trending, Watches, Charms, Jewelry and Custom from the header, so that I can find pieces by category](https://github.com/MESW-LES-2627/les-project-group-9/issues/22)
- [US-002: As a shopper, I want to see a product grid per collection with a toolbar, so that I can scan pieces quickly](https://github.com/MESW-LES-2627/les-project-group-9/issues/23)
- [US-003: As a shopper, I want to search products with predictive results, so that I find a piece fast](https://github.com/MESW-LES-2627/les-project-group-9/issues/24)
- [US-004: As a shopper, I want to filter and sort a collection by material, color, price and availability, so that I can narrow the list to what I want](https://github.com/MESW-LES-2627/les-project-group-9/issues/25)
- [US-005: As a shopper, I want to see badges (e.g. New, Limited) on product cards, so that I notice special pieces](https://github.com/MESW-LES-2627/les-project-group-9/issues/26)
- [US-006: As a shopper, I want a home page with featured pieces, a brand story and collection tiles, so that I understand the store and where to start](https://github.com/MESW-LES-2627/les-project-group-9/issues/27)

## E02: Product page (#6)

- [US-007: As a shopper, I want to see images, price and description on a product page, so that I can decide whether to buy](https://github.com/MESW-LES-2627/les-project-group-9/issues/28)
- [US-008: As a shopper, I want to pick a variant with color swatches and see the gallery jump to its image, so that I can see the exact version I choose](https://github.com/MESW-LES-2627/les-project-group-9/issues/29)
- [US-009: As a shopper, I want to see recommended products on a product page, so that I find related pieces](https://github.com/MESW-LES-2627/les-project-group-9/issues/30)
- [US-010: As a shopper, I want to add a product to my cart from its page, so that I can buy it](https://github.com/MESW-LES-2627/les-project-group-9/issues/31)

## E03: 3D visualizer (#7)

- [US-011: As a shopper, I want to rotate and zoom a 3D model of a piece on its product page, so that I can inspect it from all sides](https://github.com/MESW-LES-2627/les-project-group-9/issues/32)
- [US-013: As a shopper, I want to see the image gallery when a product has no 3D model or the model fails to load, so that the page still works](https://github.com/MESW-LES-2627/les-project-group-9/issues/34)
- [US-014: As a shopper on a phone, I want to rotate the 3D model with touch, so that I can inspect it on mobile](https://github.com/MESW-LES-2627/les-project-group-9/issues/35)
- [US-015: As a shopper, I want product pages to open quickly even when they have a 3D model, so that I can start looking at the piece without waiting](https://github.com/MESW-LES-2627/les-project-group-9/issues/36)
- [US-016: As a shopper, I want to see a "3D" marker on products that have a model, so that I know which pieces I can inspect in 3D](https://github.com/MESW-LES-2627/les-project-group-9/issues/37)

## E04: AR try-on (#8)

- [US-017: As a shopper on a phone, I want to try a piece on with my camera (AR), so that I can see how it looks on me](https://github.com/MESW-LES-2627/les-project-group-9/issues/38)
- [US-018: As a shopper, I want the Try on button to appear only when it will work, so that I do not tap a broken feature](https://github.com/MESW-LES-2627/les-project-group-9/issues/39)
- [US-019: As a shopper, I want to try on several pieces together, so that I can check whether an earring matches a necklace](https://github.com/MESW-LES-2627/les-project-group-9/issues/40)

## E05: Fitting room (multi-piece) (#9)

- [US-020: As a shopper, I want to add a piece to the fitting room from its product page, separate from the cart, so that I can try it without buying](https://github.com/MESW-LES-2627/les-project-group-9/issues/41)
- [US-021: As a shopper, I want to see all fitting room pieces together in one view, so that I can check how they look as a set](https://github.com/MESW-LES-2627/les-project-group-9/issues/42)
- [US-022: As a shopper, I want to remove a piece from the fitting room or move it to the cart, so that I can manage my selection](https://github.com/MESW-LES-2627/les-project-group-9/issues/43)
- [US-024: As a shopper, I want to see the number of pieces in my fitting room in the header, so that I know it has items](https://github.com/MESW-LES-2627/les-project-group-9/issues/45)

## E06: Make your own (restricted) (#10)

- [US-025: As a store admin, I want to mark which products can be customized and set their allowed gem colors and engraving limits in Shopify, so that only suitable pieces get the options](https://github.com/MESW-LES-2627/les-project-group-9/issues/46)
- [US-026: As a shopper, I want to add an engraving to a customizable piece, so that it is personal to me](https://github.com/MESW-LES-2627/les-project-group-9/issues/47)
- [US-028: As a shopper, I want to see the final price of my customized piece before I add it to the cart, so that I know what I pay](https://github.com/MESW-LES-2627/les-project-group-9/issues/49)
- [US-029: As a shopper, I want my engraving and gem color to appear on my order, so that the piece is made as I chose](https://github.com/MESW-LES-2627/les-project-group-9/issues/50)

## E07: Favorites and suggestions (#11)

- [US-030: As a shopper, I want to save or unsave a product with a heart button, so that I can keep pieces I like](https://github.com/MESW-LES-2627/les-project-group-9/issues/51)
- [US-031: As a shopper, I want to see my saved products on a Favorites page, so that I can come back to them](https://github.com/MESW-LES-2627/les-project-group-9/issues/52)
- [US-032: As a shopper, I want my favorites to stay saved when I come back, so that I do not lose my list](https://github.com/MESW-LES-2627/les-project-group-9/issues/53)
- [US-033: As a shopper, I want to see the number of favorites in the header, so that I know my list has items](https://github.com/MESW-LES-2627/les-project-group-9/issues/54)
- [US-034: As a shopper, I want to see suggested products based on my favorites, so that I discover pieces similar to what I like](https://github.com/MESW-LES-2627/les-project-group-9/issues/55)

## E08: Cart and checkout (#12)

- [US-035: As a shopper, I want to open a cart drawer and update or remove items, so that I can adjust my order without leaving the page](https://github.com/MESW-LES-2627/les-project-group-9/issues/56)
- [US-036: As a shopper, I want a full cart page, so that I can review my order](https://github.com/MESW-LES-2627/les-project-group-9/issues/57)
- [US-037: As a shopper, I want to apply a discount code, so that I get the discount](https://github.com/MESW-LES-2627/les-project-group-9/issues/58)
- [US-038: As a shopper, I want to check out through Shopify, so that I can pay securely](https://github.com/MESW-LES-2627/les-project-group-9/issues/59)

## E09: Account (#13)

- [US-039: As a shopper, I want to log in and out with my Shopify customer account, so that I can access my orders](https://github.com/MESW-LES-2627/les-project-group-9/issues/60)
- [US-040: As a shopper, I want to edit my first and last name, so that my account is correct](https://github.com/MESW-LES-2627/les-project-group-9/issues/61)
- [US-041: As a shopper, I want to manage my saved addresses, so that checkout is faster](https://github.com/MESW-LES-2627/les-project-group-9/issues/62)
- [US-042: As a shopper, I want to see my order history and order details, so that I can track what I bought](https://github.com/MESW-LES-2627/les-project-group-9/issues/63)

## E11: Content (#15)

- [US-044: As a shopper, I want to read blog articles, so that I learn about the brand and the pieces](https://github.com/MESW-LES-2627/les-project-group-9/issues/65)
- [US-045: As a shopper, I want to read policy and info pages, so that I know the store terms](https://github.com/MESW-LES-2627/les-project-group-9/issues/66)

## E12: Language (#16)

- [US-046: As a shopper, I want to switch between Portuguese and English (US), so that I can use the store in my language](https://github.com/MESW-LES-2627/les-project-group-9/issues/67)
- [US-047: As a shopper, I want all text, including 3D, try-on and customization labels, in my chosen language, so that the experience is consistent](https://github.com/MESW-LES-2627/les-project-group-9/issues/68)

## E13: Non-functional (#17)

- [US-048: As a shopper, I want every page to work on a phone, so that I can shop on any device](https://github.com/MESW-LES-2627/les-project-group-9/issues/69)
- [US-049: As a shopper, I want to still see the piece in photos when my device cannot show 3D or AR, so that I can always judge the product](https://github.com/MESW-LES-2627/les-project-group-9/issues/70)
